# Tipos de datos

OpenPL usa un conjunto de tipos propios para garantizar un tamaño y comportamiento
consistentes en todas las plataformas.

| Tipo | Descripción |
| :--- | :---------- |
| `Pluint` | Número entero de 32 bits sin signo |
| `Plint` | Número entero de 32 bits con signo |
| `Plvoid` | Buffer de datos |
| `Plfloat` | Números flotantes de 32 bits |
| `Plsizei` | Número entero de longitud |
| `Plenum` | Puntero de parámetros |
| `Plbool` | Booleano |
