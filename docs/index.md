<div class="openpl-grid" markdown="0">
  <div class="openpl-card">
    <h3>Simple queue-based API</h3>
    <p>Generate, bind and create with an OpenGL-style workflow — no deep Bullet knowledge required.</p>
  </div>
  <div class="openpl-card">
    <h3>Cross-platform</h3>
    <p>Build on Windows, Linux and Android from a single C/C++ core with optional Java bindings.</p>
  </div>
  <div class="openpl-card">
    <h3>Full feature set</h3>
    <p>Collision shapes, 11 constraint types, raycast vehicles, kinematic characters and soft bodies.</p>
  </div>
  <div class="openpl-card">
    <h3>Multithreaded</h3>
    <p>Optional multithreading powered by Bullet's internal task scheduler.</p>
  </div>
