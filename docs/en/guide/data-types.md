# Data types

OpenPL uses its own set of types to guarantee consistent size and behavior across all
platforms.

| Type | Description |
| :--- | :---------- |
| `Pluint` | 32-bit unsigned integer |
| `Plint` | 32-bit signed integer |
| `Plvoid` | Data buffer |
| `Plfloat` | 32-bit floating point numbers |
| `Plsizei` | Length integer |
| `Plenum` | Parameter pointer |
| `Plbool` | Boolean |
